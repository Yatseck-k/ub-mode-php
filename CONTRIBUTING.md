# Contributing

This repository maintains the `ub-mode` agent skill adapted for PHP workflows. Its optional analyzer is the separate [ub-cdmu-php](https://github.com/Yatseck-k/ub-cdmu-php) Composer package.

- Keep the three workflow stages: First Make it Work, Then Make it Right, Practice.
- Preserve upstream attribution and explain any meaningful divergence from [unclebob/ub-mode](https://github.com/unclebob/ub-mode).
- The skill must remain usable without CDMU, Python, or Docker.
- Keep commands accurate and distinguish measured results from missing evidence.
- Validate `SKILL.md` frontmatter and test instructions against a small PHP project before proposing a change.
- Update both `README.md` and `README.ru.md` when behavior or setup changes.

Use focused Conventional Commits and include the validation performed in pull requests.
